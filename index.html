Spring 2026 · Python, NetworkX · MATH 482 Combinatorial Algorithms

Minimum s-t cut with cut queries

A group study of the SODA 2026 result by Jiang, Nanongkai, and Sawettamalya, which finds an exact minimum s-t cut using only cut queries and lowers the query bound from Õ(n5/3) to Õ(n8/5). I wrote the core-algorithm sections (the witness concept, HalveGap, and FindLongEdge), the running-time analysis, and the implementation. The demo code wraps a hidden graph in a query-counting oracle, compares the O(n²) reconstruction baseline against Dinic's, and tests FindLongEdge; on n = 40 it recovers the true cut in 820 of the 1 600 queries the trivial bound allows. With Luis Navarro and Vikas Sardhara.

Fall 2025 · Python, keyword analysis · COMP 324 Networks and Security

Trustworthy chatbots

A study of how well current chatbots (ChatGPT, Google Bard, Claude) hold up on three pillars of trust: transparency, fairness, and safety. We curated prompts covering harmful instructions, sensitive data requests, and demographic-sensitive scenarios, sent the same set to each model, and scored the responses with keyword checks: does it explain a refusal, does wording shift across groups, is a harmful prompt blocked. Offline analysis only, nothing live. With Timothy Klascius and Ryan Oscar.
